# Machine Learning Practicals

A collection of 9 Machine Learning experiments implemented using Python and Scikit-learn as part of academic practical work.

## Project Structure

- `datasets/` – Contains the house price dataset.
- `experiments/` – Contains all 9 ML experiment notebooks.
- `requirements.txt` – Required Python libraries.

## Experiments

1. Simple Linear Regression
2. Multiple Linear Regression
3. Logistic Regression
4. Ridge and Lasso Regression
5. Principal Component Analysis (PCA)
6. Support Vector Machine (SVM)
7. Decision Tree Classification
8. Naive Bayes Classification
9. K-Means Clustering

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Installation

```bash
pip install -r requirements.txt
```

## Dataset

House Price Dataset used for implementing regression, classification, dimensionality reduction and clustering techniques.
